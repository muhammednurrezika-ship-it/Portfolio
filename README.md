## Publish with GitHub Pages
1. Open the `Portfolio` repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and this `README.md` from this folder.
4. Commit the changes to the repository's main branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then save.
8. After GitHub finishes publishing, the website link will appear in the Pages section.

## Important technical note
The teacher's `database.txt` is a PHP/MySQL tutorial. GitHub Pages hosts static websites and does not run PHP or MySQL. This portfolio therefore presents the PHP/MySQL topics as learning content rather than pretending to connect to a live database. A working PHP/MySQL application requires a separate PHP-capable hosting service and a configured database.
